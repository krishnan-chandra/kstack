# Prototype proof obligations

A prototype answers a question; it is not production work by default.

- **Planner:** state the hypothesis, alternatives to compare, decision criteria, and the isolation boundary that keeps experimental code out of production paths.
- **Implementer:** keep the experiment disposable and isolated, compare the promised alternatives against the stated criteria, and produce evidence for a decision. Do not silently promote prototype code into production scope.
- **Final evidence:** report the hypothesis, alternatives, observations, decision (including no-decision if inconclusive), and disposal or follow-up work.
